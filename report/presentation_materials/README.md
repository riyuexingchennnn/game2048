### 方法页应该讲清的特色与术语

**完整Expectimax：把未来的随机性算进决策。** 玩家选方向，因此在动作间取最大；落块无法控制，因此按真实概率求平均。完整求解一直推到终局，再通过缓存复用同一棋盘的答案。适合画一个“方向分支→随机落块分支”的小树。它是基于环境模型的规划，本项目没有用TD那样的样本更新来训练它。

**MCTS：用抽样试走把计算集中到值得检查的动作。** 蒙特卡洛指按环境概率抽样未来；树搜索指积累分支的访问次数和试走结果。UCT同时考虑平均估值与访问不足带来的探索项，让已有表现较好的动作和还不够了解的动作都有机会被检查。这里的探索发生在内部模拟中；最终只向真实游戏提交一个方向。有限深度试走的末端由启发式评分，所以这些模拟值是动作好坏的近似。根节点最终取平均估值最大的动作；本实现每步重新建树，没有离线学习权重。方法页列“512次模拟、深度14”，无须花时间讲它们的扫描过程。

**n-tuple：用固定位置的局部组合表示整个棋盘。** tuple是“若干项组成的一组”，n表示每组观察n个格子；5-tuple就是一次读取五个固定位置。它不是五步预测、五个动作或五个网络。把五格的数字转为指数，例如“2、4、空、2、8”对应“1、2、0、1、3”，这个组合作为查表地址，取出一个可学习的数值。不同局面若这五格相同，就共享这个表项，其他位置不同也不影响此次查表。多个位置模式的表值相加，近似整个棋盘的价值，因此能在未完整见过的棋盘上复用局部经验。局部表示也会丢失部分格子间联系，不能认为它精确表示了全局价值。

本实现有三个基础5格模式，每个模式用八种旋转／镜像读取，共24次查表；同一基础模式的八个方向共享一张表，所以是三张表，**不是24张独立表**。方法页画一个3×3棋盘，高亮第一个模式的五格，再画“指数元组→表项→各项求和”。旋转／镜像用一条小箭头说明“同类局部布局共享经验”，具体编码和容量见《额外说明》。

**后状态：先看自己能确定的移动结果。** 滑动和合并之后、随机新块出生之前的棋盘就是后状态。TD给它估计“从现在起还能接纳多少出生数字”。动作选择先比较各方向产生的后状态价值；新块出现后的真实经历再用于学习。这把已知的移动结果与随机落块分开，避免直接为每个“完整棋盘、方向”各建一套表。

**TD：用一步经历修正对未来的估计。** 暂用一句话公式：

\[
\text{误差}=\underbrace{\text{本次出生数字}+\text{下一后状态估值}}_{\text{一步学习目标}}-\text{当前后状态估值}.
\]

终局时下一项为0；主方法γ=1。此处“下一后状态”来自下一次实际选择的动作，包含训练探索动作。例如当前估值300，出生2，下一后状态估值280，则学习目标282、误差−18；α=0.1时，按归一更新使当前后状态估值约减少1.8。该例仅说明一次更新，不是实测轨迹。TD意为时间差分：利用相邻时刻的估值差更新，无须每次都等整局结束才学习。

**乐观：初始化时给价值一个偏高的期待，借此推动尝试。** 原模型把每项设为300/24=12.5，使每个后状态初始总估值为300。访问后，若实际一步目标较低，相关表项会下调；访问较少的组合可能仍保留较高估值，因而更容易被贪心选择。它给出了探索倾向，**不保证每个状态都被高估，也不保证尝试遍所有状态**；共享表项还会把更新传给其他局面。ε-greedy另行提供随机动作，两者可以共存。“乐观”不表示另加奖励，也不是预测一定能合成某个块。

参数只随方法做简短说明：原主榜TD训练30万局、初始总估值300，学习率0.1→0.03、探索率0.02→0.002；前者控制更新幅度，后者控制随机动作概率，二者均按预设时间切换。MCTS每步512次模拟、深度14；完整Expectimax不截断到有限深度。这些数值不需要逐项念出。若被问为什么这样设定、是否还有更好的取值，按《额外说明》中的实验和限制回答。

**三者的关系可用一句话收束方法部分：**完整Expectimax靠完整概率计算，MCTS靠有限抽样试走，TD把对局经验存进局部价值表，之后用查表快速决策。三者共享同一游戏规则，但学习／搜索方式和内部目标不同；不要统称为三个都经过训练的强化学习模型。

## 训练曲线

[TD真实训练曲线](figures/td_training_curve.png)来自最终30万局模型的真实日志，每个点是一批连续10,000局的统计，没有平滑。第一批平均总和318.2，最后一批626.2；虚线对应21万局后学习率调整，点线对应24万局后探索率调整。

训练曲线包含探索动作。后段上升同时受到继续学习和减少随机动作影响，不能全部归因于模型能力提高。冻结权重后的新测试平均总和是640.743，与训练末批口径不同。

Expectimax与MCTS不进行离线策略训练，不制作它们的训练曲线。不放累计测试曲线冒充训练过程。

## 最终结果：每方法1万局

测试种子均为3,000,000—3,009,999；冻结模型与参数，达到256后继续至自然终局，无步数截断，保留所有失败局。相同种子约束随机数来源，但不同动作会产生不同空格，实际落块位置仍会不同。

四项指标为：**平均终局总和、最高终局总和、256达标率、最大块分布**。这里的“得分”是终局棋盘数字之和，不是传统2048累计合并分数。

| 方法 | 平均终局总和 | 最高终局总和 | ≥256达标率 |
| --- | ---: | ---: | ---: |
| 完整Expectimax | 813.267 | 1778 | 99.54% |
| 乐观5-tuple TD | 640.743 | 1018 | 91.19% |
| MCTS | 308.698 | 626 | 47.55% |

[万局结果总览](figures/benchmark_summary.png)包括平均／最高总和及256达标率；[终局最大块分布](figures/max_tile_distribution.png)展示互斥类别比例。

类别互斥、逐行合计100%；详细比例和“恰为／至少为”的区别见《额外说明》。

结论可写：“完整Expectimax在这次测试中取得最高平均总和与达标率；TD通过离线学习实现查表决策，整体表现次之；MCTS在当前模拟预算下仍有差距。三者的训练、建表与在线搜索资源没有统一，不能据此给出同等计算资源下的优劣结论。”
